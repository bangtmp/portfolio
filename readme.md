# 🚀 Portfolio Website - Huỳnh Hữu Bằng

Website Portfolio cá nhân được xây dựng bằng **HTML5, CSS3 và JavaScript thuần**, thiết kế theo phong cách **Neo-brutalism**, giúp giới thiệu bản thân, kỹ năng, dự án và thông tin liên hệ.

## 📖 Giới thiệu

Xin chào! Tôi là **Huỳnh Hữu Bằng**, sinh viên năm nhất ngành **Công nghệ thông tin**.

Tôi yêu thích phát triển website, thiết kế giao diện và luôn không ngừng học hỏi các công nghệ mới để trở thành một **Fullstack Developer** chuyên nghiệp.

---

## ✨ Tính năng

- 🎨 Thiết kế theo phong cách **Neo-brutalism**
- 📱 Responsive trên Desktop, Tablet và Mobile
- 📌 Navigation cố định (Sticky Navbar)
- 🍔 Hamburger Menu cho thiết bị di động
- ✨ Hiệu ứng Fade In Up khi cuộn trang
- 🎯 Scroll Spy tự động đánh dấu menu đang xem
- 🚀 Cuộn mượt (Smooth Scroll)
- 💼 Hiển thị dự án dạng Card
- 📧 Form liên hệ có kiểm tra dữ liệu bằng JavaScript
- 🔝 Nút quay lại đầu trang (Back to Top)
- ♿ Hỗ trợ Accessibility cơ bản (ARIA, Focus State)
- ⚡ Không sử dụng Framework
