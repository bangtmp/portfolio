01 Giới thiệu về tôi

Xin chào! 👋

Tôi là Huỳnh Hữu Bằng, sinh viên năm nhất ngành Công nghệ thông tin với niềm đam mê lớn với lập trình web và thiết kế giao diện. Tôi thích biến những ý tưởng thành sản phẩm thực tế và luôn tò mò tìm hiểu những công nghệ mới.

Hiện tại tôi đang tập trung trau dồi HTML, CSS, JavaScript cùng các kiến thức nền tảng về thuật toán và cấu trúc dữ liệu. Mục tiêu của tôi là xây dựng một nền móng vững chắc, không chỉ giỏi viết code mà còn hiểu sâu cách sản phẩm vận hành từ giao diện đến hệ thống.

Mục tiêu của tôi 🎯

  • Trở thành Fullstack Developer chuyên nghiệp
  • Không ngừng học hỏi và trau dồi kỹ năng lập trình
  • Tham gia các dự án thực tế để tích lũy kinh nghiệm
  • Kết nối với cộng đồng lập trình viên

03 Lộ trình phát triển

Hành trình trở thành Fullstack Developer của tôi, chia theo từng giai đoạn rõ ràng.

  1. 01

    Nền tảng

    Xây nền móng vững chắc: HTML, CSS, JavaScript, TypeScript cùng Git — đủ khả năng tự tay dựng và quản lý một dự án web hoàn chỉnh.

    • HTML
    • CSS
    • JavaScript
    • TypeScript
    • Git & GitHub
  2. 02

    Frontend

    Làm chủ giao diện người dùng với React và Next.js, trau dồi responsive design cùng UI/UX để tạo ra trải nghiệm vừa đẹp vừa dễ dùng.

    • React
    • Next.js
    • Responsive
    • UI/UX
  3. 03

    Backend

    Đang ở đây

    Xây dựng phía máy chủ với Node.js, thiết kế API, lưu trữ dữ liệu với MongoDB và triển khai sản phẩm lên môi trường thực tế.

    • Node.js
    • API
    • MongoDB
    • Deploy
  4. 04

    Fullstack & sự nghiệp

    Kết hợp toàn bộ kỹ năng để hoàn thiện sản phẩm từ giao diện đến hệ thống, thực hiện những dự án thật và hướng tới kỳ thực tập.

    • Dự án thật
    • Internship
    • Fullstack
